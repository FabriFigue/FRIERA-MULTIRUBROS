Script SQL para ejecutar en Supabase Para crear las 4 tablas necesarias en tu proyecto de Supabase, andá al panel de Supabase > SQL Editor > New Query, pegá este bloque y dale a Run: SQL -- 1. Tabla para el Semillero de Ideas & Tips create table if not exists ideas ( id bigint generated by default as identity primary key, titulo text not null, categoria text default 'general', autor text default 'Fribera', texto text not null, estado text default 'pendiente', fecha date default current_date, created_at timestamp with time zone default timezone('utc'::text, now()) ); -- 2. Tabla de Clientes create table if not exists clientes ( id bigint generated by default as identity primary key, nombre text not null, direccion text, matafuegos int default 1, vencimiento date, created_at timestamp with time zone default timezone('utc'::text, now()) ); -- 3. Tabla de Stock create table if not exists stock ( id bigint generated by default as identity primary key, producto text not null, tipo text, capacidad text, cant int default 0, min int default 0, precio numeric default 0, created_at timestamp with time zone default timezone('utc'::text, now()) ); -- 4. Tabla de Ventas create table if not exists ventas ( id bigint generated by default as identity primary key, fecha date default current_date, cliente text not null, detalle text, total numeric default 0, created_at timestamp with time zone default timezone('utc'::text, now()) ); -- Políticas de acceso público (para prototipo sin login obligatorio) alter table ideas enable row level security; alter table clientes enable row level security; alter table stock enable row level security; alter table ventas enable row level security; create policy "Permitir todo en ideas" on ideas for all using (true) with check (true); create policy "Permitir todo en clientes" on clientes for all using (true) with check (true); create policy "Permitir todo en stock" on stock for all using (true) with check (true); create policy "Permitir todo en ventas" on ventas for all using (true) with check (true); 2.
